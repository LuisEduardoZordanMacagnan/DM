A. O que é uma View no Android Framework?
- View é uma classe JAVA ao qual cria objetos de visualização e interação em telas. Tendo algum modelos já feitos como PlainText, EditText, Image, Button ou podendo importar os elementos básicos de uma view em uma nova classe criando um view tootalmente nova.

B. O que é um ViewGroup no contexto da interface do Android?
- Viewgroup é literalmente um grupo de views, no caso um elemento view base que vai armazenar outras views, em resumo, um layout

C. Qual é a função dos LayoutParams dentro de um ViewGroup?
- São os parametros de layout, ou seja, suas definições como tamanho, "constraint"s e posições dos elementos da tela.

D. Por que diferentes ViewGroups (como LinearLayout, ConstraintLayout, FrameLayout) utilizam subclasses específicas de LayoutParams?
- Porque cada view possuem suas definições, configurações e maneira de se organizar na tela, por exemplo linearlayout funciona como o flex do html e css, sendo organizado através de "caixas", enquanto constraintlayout é feito com base nas extremidades da tela, a distância sobre os lados e o framelaout deixa tudo "em cima do outro"
